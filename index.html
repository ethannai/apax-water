📚 二元母液配置與指南

1. 二元母液配製規格 (100ml 玻璃瓶)
  • 瓶 A (純硬度 GH)：取 4.0 ml DSW-618 原液，加純水補滿至 100 ml。（無碳酸氫根，常溫存放絕不結晶）
  • 瓶 B (純緩衝 KH)：取 0.84 g 食用小蘇打粉，加純水補滿至 100 ml。（濃度僅 0.84%，完全遠離飽和線，告別結晶）
2. 各處理法標準基準 (每 600ml 純水)
配方 瓶 A (GH) 瓶 B (KH) 風味重點
Cupping 2.3 ml 1.2 ml 全頻明亮、高解析
Washed 2.0 ml 1.0 ml 柑橘果酸、花香清脆
Natural 1.7 ml 2.4 ml 莓果熟果、圓潤修酸
Honey 1.8 ml 1.8 ml 蜜糖質地、甜感延伸
Fermented 1.5 ml 3.0 ml 修飾刺酸、厚實底蘊
Balanced 2.0 ml 2.0 ml 酸甜黃金比、百搭通配
3. 吧台防呆操作叮嚀
  • 兩瓶分開注入：先加純水進手沖壺或水瓶，再分別以兩支獨立針筒抽取瓶 A 與瓶 B 注入。
  • 嚴禁針筒混用：抽取瓶 A 的針筒切勿伸入瓶 B，避免瓶口微量離子交錯污染。
  • 常溫避光存放：母液直接放置在吧台常溫陰涼處，不可冷藏。
